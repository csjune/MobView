# AMO listing

**Name**: MobView

**Summary**: Switch individual sites to their mobile version with one click on the toolbar button. Other sites stay untouched.

**Description**:
MobView makes chosen sites load their mobile version. Click the toolbar button on any site
to toggle mobile view for that site only; all other sites stay untouched.

- Sends a mobile user-agent header to enabled sites only
- Also adjusts what page scripts see (navigator.userAgent, platform, maxTouchPoints and more),
  so sites that detect devices in JavaScript switch too
- Manage enabled sites and set your own user-agent string on the options page
- Dark mode support

Privacy: MobView does not collect or transmit any data. All settings are stored locally
in your browser.
